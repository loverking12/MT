Put your songs in this folder (mp3, m4a, ogg or wav).

- The site shuffles ALL the songs in this folder. The song title shown is the file name.
- After adding or removing songs, stop the dev server and start it again, or rebuild.
- Keep each song around 3-4 MB so it downloads fast on the phone.
- The footer has a "Save songs for offline" button: tap it once on Wi-Fi to download them all.
- Only use songs you have the right to publish: the site is public on GitHub Pages.
